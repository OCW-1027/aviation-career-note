# AI 작업 분담 — Claude · GPT (2026-10-09 정리)

GPT 제안(10/9)을 바탕으로 Claude가 최종 정리한 것입니다. 다음 작업부터 이 기준으로 진행합니다.

## 1. 기본 원칙
- **기준은 하나**: PC 「콘텐츠」 폴더 → (사용자 업로드) → GitHub main. GPT는 GitHub에 올라간 것만 봅니다. 검토를 맡길 때는 먼저 업로드합니다.
- **사이트 파일은 Claude만 고칩니다.** 두 AI가 같은 파일을 고치지 않습니다.
- **주고받는 것은 정해진 형식의 파일**로 합니다(설명문이 아니라 데이터). 받은 쪽이 다시 정리하는 일이 줄어 토큰이 가장 많이 절약됩니다.
- **매번 전체 설명을 반복하지 않습니다.** 이번 작업 목표 + 관련 파일만 전달합니다. 전체 상황은 `00_제작로드맵.md`.
- **작업 분실 방지**: Claude는 파일이 하나 끝날 때마다 PC 폴더에 저장합니다(10/9에 클라우드 작업 공간 초기화로 완성본을 잃은 뒤의 규칙).

| 레슨 원고(그림·퀴즈·연결 포함) | 주담당 | 자료 조사, 내용 검토 |
| 회화 장면 대사 | 형식 검사·반영 | **주담당** — `00_회화데이터_작성규칙.md` 형식 그대로 |
| 게임(Airport Shift) 미션·사건 연쇄 | 형식 정의·구현 | **주담당** — 312개 중 우수 소재 선별·고도화 |

## 3. GPT 제안에서 바꾼 점
1. **레슨 원고는 Claude가 계속 씁니다.** GPT 초안을 사이트 형식(블록·그림·퀴즈·이전/다음)으로 다시 고치는 비용이 처음부터 쓰는 것보다 큽니다. GPT는 자료 조사와 검토에 집중합니다.
2. **조사 결과에는 출처와 날짜가 필수.** 출처 없는 내용은 Claude가 다시 조사해야 해서 오히려 토큰이 늘어납니다.
3. **회화·게임 데이터는 형식 검사만으로 반영**할 수 있게, GPT는 지정한 형식에서 벗어나지 않게 씁니다(필드 이름·id 규칙·3개 언어 모두).

## 4. 동의한 점(그대로 진행)
- 게임은 수보다 재미 검증 먼저: 체크인 1편, 3~5분, 연결된 사건 2~3개, 유효한 해결 경로 2개 이상, 끝난 뒤 리플레이와 관련 레슨 연결.
- **필수 준수 조건**(안전·보안·여행서류·탑재 제한)은 선택지에서 어길 수 없고, 고민은 **적법한 방법들 사이의 최적화**(시간·비용·만족·업무량)에서 합니다. (스테이션 운영 5-5도 같은 원칙으로 작성)
- AI 대화 기능 비용·Supabase 무료 한도는 실제 사용량을 재 보고 결정. 음성·실명·여권 사진은 저장하지 않는 설계, 게임 속 개인 정보는 모두 가상.

## 7. 영상 강의와 게임 (10/9 결정)
- 영상: 사이트 오픈 전에 대표 영상 5~8편 → 이후 정기 업데이트. 제작은 Claude가 실제 도구 화면을 자동 조작·녹화하고 3개 국어 음성·자막을 붙이는 방식으로 시범 1편(탑재관리)부터. GPT는 대본·장면 구성·자막 검수.
- 공개: 무료 체험 영상은 YouTube(사이트에 삽입), 회원 전용은 회원 기능(E1) 이후 서명된 재생 주소(Cloudflare Stream 등). YouTube 멤버십 자동 부여는 불가.
- 7일 무료 체험 대신 「체험 강의」 페이지(영상 + 실습 1개 + 퀴즈).
- 게임: 최종 목표는 GPT 원안(복합 항공 시뮬레이션 RPG). 첫 모듈은 체크인, 처음부터 공통 항공편 엔진 위에서 만든다. 무료로 첫 항공편 출발까지 완결.

## 과제 1 (우선): 회화 장면 확대 — 비정상 운항 중심

사용자 의견: 장면이 20개뿐이고, 공항 쪽이 적고, 특히 비정상 운항 상황이 부족하며, 한 장면의 대화가 너무 짧다.

### 목표 수량 (현재 20 → 약 65)
| 분류 `cat` | 추가 | 내용 |
|---|---|---|
| `work` 공항·기내 업무 | **+24** | 그중 **비정상 운항 14개 이상** (아래 목록) |
| `travel` 여행 | +6 | 공항 이용자 입장: 결항 안내를 받는 승객, 환승, 렌터카, 분실물 등 |
| `life` 일상생활 | +9 | 은행, 휴대폰 개통, 집 구하기, 이사, 약국, 택배, 미용실, 학교 연락, 이웃 소음 |
| `office` 직장 | +6 | 보고, 회의 일정 조정, 실수 사과, 거래처 전화, 휴가 신청, 인수인계 |

### 비정상 운항 장면 후보 (14개 이상 고르기)
- 당일 결항 안내와 대체편·환불 선택
- 장시간 지연(3시간 이상), 식사 쿠폰 안내
- 회항(다이버트)한 승객 안내
- 오버부킹, 자원자 모집과 보상 안내
- 기재 변경으로 좌석이 바뀐 승객
- 기상 악화로 탑승 대기, 기내 장시간 대기
- 시스템 장애로 수작업 체크인
- 환승편을 놓친 승객의 재예약
- 결항으로 숙박이 필요한 승객(호텔 안내)
- 여행 서류가 부족해 탑승할 수 없는 승객
- 위탁 수하물에서 위험물·보조배터리 발견
- 기내 응급 환자 발생 후 도착지 대응
- 수하물 파손·지연 접수
- 탑승 마감 후 도착한 승객
- 태풍·대설로 공항 폐쇄 예고
- 승무원 근무 시간 초과로 출발이 늦어짐

### 작성 기준
- 장면마다 **14~20줄**: A·B가 번갈아 말하고, 중간에 한 번 상황이 바뀌는 흐름(돌발 사항)을 넣어 주세요.
- **alt 3개 이상**, **확인 문제 3개**, **`ai:{goal, twist}`** (3개 국어)
- 난이도 lv 1~3을 고르게 섞기. 비정상 운항은 lv 2~3 중심.
- **항공사 규정을 약속하지 않기**: 보상, 환불, 이름 수정처럼 회사마다 다른 것은 「規定によります」「確認いたします」 식으로 씁니다.
- **일본어가 가장 중요합니다.** 실제 공항 직원이 쓰는 자연스러운 경어로 씁니다. 「の」를 과하게 쓰지 말고(航空の実務 ✕ → 航空実務 ○), 외래어는 꼭 필요할 때만 씁니다.
- 한국어는 번역투 없이, 영어는 자연스럽게 쓰고 아포스트로피는 ’를 사용합니다.
- 이름·항공사·편명은 모두 가상으로 합니다.
- 규정과 관련된 내용은 출처 URL과 확인 날짜를 별도 목록으로 붙여 주세요.

### 전달 방법
- **5장면씩** 파일 하나로 주세요: `talk_data_g01.js`, `talk_data_g02.js` …
  ```js
  window.TALK=window.TALK||[];
  window.TALK.push({…},{…});
  ```
- id는 규칙 문서 4장을 따르고, 기존 id와 겹치지 않게 합니다. 기존 id 목록은 `talk_data.js`에 있습니다.
- 지난번 Batch 01(초과 수하물, 악천후 결항, 수하물 파손, 본사 보고)도 **14줄 이상으로 늘려서** 이 형식으로 다시 주세요.

## 과제 2 (과제 1 다음): 강좌 안 「AI와 이 업무 연습하기」 데이터

GPT가 제안한 기능입니다. Claude가 레슨 화면에 버튼을 만들고, 누르면 사이트 안 AI 대화가 그 설정으로 시작됩니다.

- 대상: 여객운송(1_), 현장 사례(3_), CIQ(24_), 항공화물(6_), 스테이션 운영(16_) 강좌에서 회화 연습이 자연스러운 레슨 **30개**
- 형식: 파일 `lesson_rp_g01.js`
  ```js
  window.LESSON_RP=(window.LESSON_RP||[]).concat([
  { course:'1_지상직여객운송입문', lesson:'4-2',          // 강좌 폴더 이름과 레슨 번호
    title:{ja,ko,en},                                      // 연습 이름
    scene:{ja,ko,en},                                      // 상황 1~2문장
    ai:{ role:{ja,ko,en}, persona:{ja,ko,en} },            // AI 역할과 성격
    me:{ role:{ja,ko,en} },                                // 학습자 역할
    goal:{ja,ko,en}, twist:{ja,ko,en},                     // 목표, 중간에 생기는 일
    opener:{ja,ko,en},                                     // AI의 첫마디
    lv:2 }
  ]);
  ```
- 레슨 번호는 사이트 강좌 목차에서 확인해 주세요.

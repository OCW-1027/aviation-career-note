# 회화 연습 데이터 작성 규칙 (talk_data.js)

> 대상 페이지: `会話練習_日韓英.html` (공개 사이트 주소는 `talk.html`)
> 데이터 파일: `talk_data.js` (사이트 맨 위 폴더)
> 자유 대화 주제: `talk_topics.js` (사이트 맨 위 폴더) — 9번 참고
> 이 문서(*.md)는 공개되지 않습니다. GPT 등에게 새 장면·주제를 만들게 할 때 이 문서를 그대로 건네면 됩니다.

---

## 1. 한눈에 보기

- 대화 1개 = `{ … }` 1개. `window.TALK.push( … );` 안에 쉼표로 이어서 넣습니다.
- 모든 대사는 **일본어(ja)·히라가나 읽기(jr)·한국어(ko)·영어(en)** 네 가지를 함께 씁니다.
- 한 장면에 대사 **14~20줄**(2026-10-10 변경: 대화가 짧다는 의견), 확인 문제 **2~3개**, 바꿔 말하기(alt)는 **중요한 줄 2~3개**에.
- 이름·회사·가게는 **모두 가상**입니다. 실제 회사 이름(항공사·호텔 체인·편의점 브랜드 등)은 쓰지 않습니다.

## 2. 형식

```js
{id:'air-checkin-1',            // 아래 4번 참고. 한 번 공개하면 바꾸지 않음
 cat:'work',                    // 'work' | 'travel' | 'life' | 'office'
 lv:1,                          // 난이도 1(쉬움)·2(보통)·3(어려움)
 title:{ja:'',ko:'',en:''},     // 대화 이름 (짧게)
 scene:{ja:'',ko:'',en:''},     // 상황 설명 1문장
 roles:{A:{ja:'',ko:'',en:''}, B:{ja:'',ko:'',en:''}},   // 역할 이름
 lines:[
   {r:'A', ja:'', jr:'', ko:'', en:'',
    alt:[{ja:'',jr:'',ko:'',en:''}],     // (선택) 같은 뜻의 다른 표현
    note:{ja:'',ko:'',en:''}}            // (선택) 포인트 해설 1~2문장
 ],
 check:[
   {q:{ja:'',ko:'',en:''},               // 질문 (화면에서는 '힌트 언어'로 표시)
    opts:[{ja:'',ko:'',en:''},{…},{…}],  // 선택지 3개 (화면에서는 '연습할 언어'로 표시)
    a:0}                                 // 정답 번호 (0부터)
 ],
 ai:{goal:{ja:'',ko:'',en:''},           // (권장) 「AI와 대화」에서 쓰는 대화 목표 1문장
     twist:{ja:'',ko:'',en:''}}          // (권장) 대화 도중 AI가 일으키는 돌발 상황 1문장
}
```

| 항목 | 필수 | 설명 |
|---|---|---|
| `id` | ○ | 영문 소문자·숫자·`-`만. 기록과 「내 표현」이 이 id로 저장되므로 공개 후 변경 금지 |
| `cat` | ○ | 분류 4가지 중 하나 |
| `lv` | ○ | 1~3 |
| `title` `roles` | ○ | 세 언어 모두 |
| `scene` | 권장 | 없으면 표시하지 않음 |
| `lines` | ○ | 14~20줄. `r`은 `'A'` 또는 `'B'` |
| `jr` | ○ | 일본어 대사의 읽기 (아래 3번) |
| `alt` `note` | 선택 | 없어도 화면은 동작함 |
| `check` | 권장 | 2~3문제. 없으면 '확인' 탭에 안내만 나옴 |
| `ai` | 권장 | 「AI와 대화」용 목표(`goal`)와 돌발 상황(`twist`). 아래 8번. 없으면 그 줄만 빠진 프롬프트로 동작 |

빠진 언어가 있으면 화면은 일본어 → 영어 → 한국어 순으로 대신 보여 주지만, **원칙적으로 세 언어 모두 채웁니다.**

## 3. 문장 규칙

**일본어 (ja)**
- 정중체(です・ます). 손님 응대 장면은 자연스러운 경어(いたします・ございます)까지.
- 쉬운 말. 일본어 고유어가 있으면 외래어를 피합니다 (예: サイン → 署名, レジ → お会計). 단 チェックイン·パスポート·ホテル처럼 일상에서 그 말밖에 안 쓰는 것은 그대로 둡니다.
- 친한 선배·이웃처럼 반말이 자연스러운 역할은 반말도 허용 (그 경우 note로 한마디 설명).

**읽기 (jr)**
- 일본어 대사 전체를 **히라가나**로. 한자는 히라가나로 바꾸고, **가타카나 단어는 그대로** 둡니다.
- 문절(文節) 사이에 **반각 스페이스**. 구두점(、。？「」……)은 ja와 똑같이.
- 숫자는 읽는 대로 (예: `10時20分` → `じゅうじ にじゅっぷん`, `805号室` → `はちまる ごごうしつ`).
- 예: `ja:'パスポートを拝見してもよろしいですか。'` → `jr:'パスポートを はいけん しても よろしいですか。'`

**한국어 (ko)**
- 번역투 금지. 그 상황에서 한국 사람이 실제로 하는 말로. (예: 「どうぞ」→ “여기 있어요”, 「ご安心ください」→ “걱정하지 마세요”)
- 손님 응대는 ‘-습니다/-세요’, 친구·동료 사이는 ‘-요’체 중심.

**영어 (en)**
- 자연스러운 구어. 직역하지 않습니다.
- **작은따옴표(')는 쓰지 말고 ’(곡선 아포스트로피)를 씁니다.** (데이터가 '…'로 감싸져 있어서 '를 쓰면 파일이 깨집니다.) 예: `I’m` `don’t`

**공통**
- 이름은 가상의 이름 (예: 김민아, 이준, 박, 사토, 야마다, 나카무라). 회사·가게도 가상 (예: 아오조라상사, 미도리물류, 사쿠라 식당).
- 전화번호는 `090-1234-5678`처럼 누가 봐도 예시인 번호.
- 실제 규정·요금처럼 바뀌는 정보는 넣지 않습니다.

## 4. id 정하는 법

`분류 머리말-주제-번호`

| cat | 머리말 | 예 |
|---|---|---|
| work (공항·기내 업무) | `air` | `air-checkin-1`, `air-gate-delay-1` |
| travel (여행) | `trv` | `trv-hotel-1` |
| life (일상생활) | `life` | `life-clinic-1` |
| office (직장 대화) | `off` | `off-help-1` |

같은 주제로 하나 더 만들면 번호만 올립니다 (`air-checkin-2`). 기존 id와 겹치면 먼저 읽은 쪽만 쓰입니다.

## 5. 바꿔 말하기(alt)와 확인 문제(check) 만드는 법

**alt**
- 그 장면에서 **꼭 익혀야 할 줄**(사과, 요청, 핵심 안내 등)에 1~2개.
- 같은 뜻이지만 말투나 표현이 다른 것 (더 정중하게/더 짧게/다른 단어로). 네 언어 모두, jr 포함.

**check**
- 질문은 “이 상황에서 뭐라고 말합니까?” 형식. 상황은 질문 안에 짧게 설명.
- 선택지 3개: 정답 1개 + 그럴듯하지만 틀린 것 2개 (무례함, 엉뚱한 대답, 다른 질문에 대한 답 등).
- 정답은 대사(또는 alt)에 나온 표현을 그대로 쓰면 복습이 됩니다.
- `a`는 정답 번호(0부터). 화면에서 순서를 섞어 보여 주므로 정답을 늘 0번에 둬도 괜찮지만, 섞어 두면 더 좋습니다.

## 7. 넣는 방법

1. **같은 파일에 추가**: `talk_data.js` 맨 끝의 `);` 바로 앞에, 마지막 `}` 뒤에 쉼표를 붙이고 새 `{ … }`를 넣습니다.
2. **파일을 나눌 때** (장면이 많아지면 권장): `talk_data2.js`를 만들고 내용을 아래 형태로.
   ```js
   window.TALK=window.TALK||[];
   window.TALK.push(
   {…},
   {…}
   );
   ```
   그리고 `会話練習_日韓英.html` 안의 `<script src="talk_data.js"></script>` 바로 다음 줄에 `<script src="talk_data2.js"></script>`를 한 줄 추가합니다.
3. 넣은 뒤 확인: 페이지를 열어 목록에 새 장면이 보이는지, 네 가지 모드(듣기·역할 연습·바꿔 말하기·확인)가 다 열리는지 봅니다. 화면이 비면 대개 쉼표 누락이나 영어의 `'` 때문입니다.

## 8. AI 대화용 필드 (`ai`)

장면 화면의 「AI와 대화」 버튼은 이 장면을 AI와 자유롭게 역할극으로 이어 갑니다. 학습자가 고르지 않은 역할을 AI가 맡고, 아래 두 문장이 AI에게 주는 프롬프트에 들어갑니다.

```js
ai:{goal:{ja:'名前のちがいを確かめて直し、チェックインを最後まで終える。',ko:'이름 차이를 확인해서 고치고 체크인을 끝까지 마친다.',en:'Confirm and correct the name, then finish check-in.'},
    twist:{ja:'スーツケースが、重さの上限を3キロこえている。',ko:'캐리어가 무게 제한을 3킬로 넘는다.',en:'The suitcase is 3 kg over the weight limit.'}},
```

- **goal**: 이 대화가 어디까지 가면 끝인지 1문장. 학습자가 **A·B 어느 역할을 골라도** 통하도록 씁니다 (“~를 확인해서 ~를 마친다”처럼 대화 전체의 목표).
- **twist**: 대화 중간에 AI가 자연스럽게 일으키는 일 1문장. **장면 설명(scene)에 이미 있는 일은 쓰지 않고** 새 문제를 하나 더합니다 (짐 무게 초과, 시간이 없음, 서류를 깜빡함 등). 위험하거나 무서운 일(사고·범죄)은 피합니다.
- 세 언어 모두. 문장 규칙은 3번과 같음 (영어는 ’ 사용).
- 위치는 어디든 되지만, 지금 20개 장면은 `{id:…,cat:…,lv:…,` 바로 다음 줄에 넣었습니다.

## 9. 자유 대화 주제 (`talk_topics.js`)

「자유 대화(AI)」 화면(`talk.html#ai`)의 주제 카드입니다. 대사는 없고, AI에게 줄 설정만 씁니다.

```js
{id:'t-weekend',lv:1,persona:'colleague',
 title:{ja:'週末の予定',ko:'주말 계획',en:'Weekend plans'},
 sit:{ja:'金曜日の夕方、帰る前に同僚と週末の予定を話します。',ko:'금요일 저녁, 퇴근 전에 동료와 주말 계획을 이야기합니다.',en:'On Friday evening, before heading home, you chat with a colleague about the weekend.'},
 ai:{ja:'職場の同僚。気さくで、話が好き',ko:'직장 동료. 편하고 이야기를 좋아함',en:'A friendly, talkative colleague'},
 me:{ja:'同僚',ko:'동료',en:'A colleague'},
 goal:{ja:'週末に何をするか伝え、相手の予定も聞く。',ko:'주말에 무엇을 할지 말하고 상대의 계획도 묻는다.',en:'Say what you will do at the weekend and ask about their plans.'},
 twist:{ja:'同僚が、日曜日にいっしょに出かけないかと誘ってくる。',ko:'동료가 일요일에 같이 놀러 가자고 한다.',en:'Your colleague invites you to go out together on Sunday.'}},
```

| 항목 | 필수 | 설명 |
|---|---|---|
| `id` | ○ | `t-` 로 시작. 영문 소문자·숫자·`-` |
| `lv` | ○ | 1~3. AI 말투의 기준이 됨 (1 아주 쉬움 · 2 일상 회화 · 3 자연스러운 표현·경어) |
| `persona` | ○ | AI의 입장. `friend`(친구) · `neighbor`(이웃) · `colleague`(직장 동료) · `exchange`(언어 교환 상대) · `staff`(가게 직원) · `interviewer`(면접관) 중 하나. 카드 위의 작은 글자로 표시 |
| `title` | ○ | 주제 이름 (짧게) |
| `sit` | ○ | 상황 1문장 (카드 설명과 프롬프트에 그대로 들어감) |
| `ai` | ○ | AI의 역할과 **성격** (예: “친구. 이것저것 관심이 많고 질문을 자주 함”). **이름은 쓰지 않음** — AI가 연습 언어에 맞는 가상의 이름을 붙임 |
| `me` | ○ | 학습자의 역할 |
| `goal` | ○ | 대화 목표 1문장 |
| `twist` | 선택 | 대화 중간에 생기는 일 1문장 |

- 넣는 곳: `talk_topics.js` 맨 끝 `);` 바로 앞. 같은 id는 먼저 읽은 것만 쓰입니다.
- 정치·종교처럼 의견이 크게 갈리는 주제, 실제 회사·인물 이름은 넣지 않습니다.
- 일본어는 쉬운 말(외래어는 그 말밖에 없을 때만, 예: カフェ → 喫茶店), 한국어는 번역투 없이, 영어는 ’ 사용.

**AI 프롬프트는 페이지가 자동으로 만듭니다.** 데이터에는 상황·역할·목표·돌발 상황만 쓰면 되고, “연습 언어로만 말하기”, “한 번에 1~2문장”, “질문으로 대화 이어 가기”, “틀린 곳 짧게 고치기”, “힌트 2개”, “끝/おわり/end 라고 하면 정리” 같은 규칙은 쓰지 않습니다.

## 10. GPT에게 건넬 때의 한 줄 요약

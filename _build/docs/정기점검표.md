# 정기 점검표 (T-23, 2026-11-12)

## 구조
- `_build/schedule.json` — 점검 항목(매주·매월·분기·매년·AIRAC)
- `node _build/due.mjs [YYYY-MM]` — 그달 할 일을 체크리스트로 출력
- 빌드할 때마다 「이번 달 정기 점검」이 출력됨(빌드는 멈추지 않음). 요율(rates_jp.js)의 확인 월은 빌드가 따로 알려 줌
- 매월 1일 예약 작업이 그달 점검 목록과 AIP 근거 문장 점검 결과를 알려 줌
